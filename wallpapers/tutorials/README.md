## 如何操作

1. 将鼠标移动到三颗陨石中间。
2. 按住鼠标启动引力，让两侧陨石逐渐靠近。
3. 让三颗陨石的**实体轮廓实际接触**，即可触发 **CHAIN ×3，+300 分**。
4. 点击教程内的「重新播放教程」，可以从相同初始位置重复观察。

## 演示性质（公开说明）

这是一个**可重复的预设位置教学场景**，不代表随机出生场景中一定能轻易完成三连撞。

教学页面从正式版 V3.2.3 的完整 HTML 派生，使用相同的引力加速度、速度更新、陨石多边形碰撞和计分函数。为了方便演示，只预置三颗陨石的初始位置与初始速度，并通过正常的 pointerdown / mousedown / pointerup / mouseup 鼠标事件驱动游戏；**不直接修改运动中的陨石速度，不调用碰撞判定进行作弊，不增加引力冲击波或碰撞范围。**

演示积分使用独立的本机存储键，不与正式壁纸的个人积分混用。
